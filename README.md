# Site Áustria

Projeto escolar desenvolvido com HTML5, Tailwind CSS e JavaScript. Não utiliza PHP nem banco de dados.

## Como abrir

1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador ou use a extensão Live Server do VS Code.
3. Mantenha conexão com a internet para carregar o Tailwind CSS e as fotografias externas do Unsplash.

## Estrutura

- `index.html`: página completa do site.
- `assets/img/`: imagens e ilustrações locais.

O layout possui ajustes para celular, tablet e desktop.
